# 栗子看海工具 1.2.5 使用说明书（小白版）

本书写给第一次用看海工具的玩家。你不需要懂文件格式，也不需要懂编程。照着每一章的步骤点按钮，就能改个性、改武将、改战法、改地图，并且在游戏里看到结果。

- 适用环境：Windows 64 位，曲海金戈 V2.7（简中）
- 版本：1.2.5
- 发布日期：2026 年 11 月 17 日
- 配套文件：`使用说明` 文件夹内的《增量更新说明》，网站上的历史版本说明

## 怎样用这本书

| 标记 | 意思 |
|---|---|
| 提示 | 省时间的小技巧，看到可以直接照做 |
| 注意 | 做错了会白改一次，建议先看一眼 |
| 危险 | 可能影响存档或游戏数据，必须先备份 |

全书按钮名、页面名都用中文引号标出，例如「保存到文件」。书里出现的 `D:\Entertainment\314曲海V2.7` 只是示例，以你电脑上实际安装的位置为准。

# 第 1 章 三分钟上手

## 1.1 先搞懂整个流程

看海工具做的事情只有一件：**改游戏目录里的数据文件**，游戏下次读取时使用新数据。所以流程永远是这五步：

1. 装工具、选游戏。
2. 在对应页面找到要改的内容。
3. 改完点页面上的保存按钮。
4. 完整退出游戏再重新打开（有些改动要新开剧本）。
5. 进游戏核对结果。

## 1.2 第一次安装（7 步）

| 步骤 | 做什么 | 注意 |
|---:|---|---|
| 1 | 下载 `kanhai-suite-1.2.5.zip` | 请下完整包，不要只下 EXE |
| 2 | 右键压缩包 → 解压到游戏目录下的独立文件夹，例如 `D:\Entertainment\314曲海V2.7\栗子看海工具` | 不要在压缩包里直接双击运行 |
| 3 | 打开解压后的文件夹，确认有 `看海工具.exe`、`fonts`、`gate-assets`、`version-dll-assets`、`使用说明` | 缺文件说明没解压完整 |
| 4 | 双击 `看海工具.exe` | 第一次启动较慢，等窗口出现 |
| 5 | 进「游戏主程序」页，点「选择 EXE」，选你实际在用的游戏主程序 | 一般是 `SAN14PK_SC.exe` 一类 |
| 6 | 进「个性编辑」或「武将编辑」，点「选择游戏根目录」 | 选能看到 EXE、`0010_SC`、`0000`、`Profile` 的那一层 |
| 7 | 看页面上的路径栏，确认指向的文件名对得上 | 不对就点「手动配置」 |

**提示**：压缩包里的主程序文件名前面有一个栗子图标，本书为了排版统一写成「看海工具.exe」，看到名字前面带栗子的 EXE 就是它。

**如果双击后没有窗口**：先确认是完整解压后运行；再确认是从曲海目录下的工具文件夹启动，而不是在 `%TEMP%`、压缩包临时目录或网盘同步目录里运行。若有安全软件提示，看清提示里的文件名和原因再决定。

## 1.3 第一次改一个武将（完整走一遍）

1. 退出游戏（先退出，避免游戏把内存里的旧数据写回文件）。
2. 打开工具 → 左侧「武将编辑」。
3. 顶部来源保持「剧本武将」。
4. 在搜索框输入一个你熟悉的武将名，例如「姬发」，点左侧列表里的他。
5. 在「基本」页把「统率」滑条往右拖一点，数值框会同步变化。
6. 点页面上的「保存到文件」。
7. 点「重新载入」，确认数值还是你改后的值。
8. 打开游戏，**新开**一局这个剧本，进武将详情核对能力值。

改成功了。后面所有页面的用法都一样：找到对象 → 改 → 保存到文件 → 重新载入确认 → 重启游戏核对。

## 1.4 记住三句话

| 你看到的按钮 | 它做什么 | 什么时候用 |
|---|---|---|
| 「保存到文件」 | 把本页改动写进当前路径栏里的数据文件 | 个性、武将、战法、阵型、府域、地图 |
| 「保存并应用」 | 保存游戏功能开关，并把配套 DLL 部署到游戏目录 | 只有「游戏主程序」页的功能开关用它 |
| 「重新载入」 | 从文件重新读一遍，放弃未保存的改动 | 保存后核对、改乱了想重来 |

# 第 2 章 认清三个目录和两类保存

## 2.1 游戏根目录是什么

打开这个文件夹，能同时看到游戏 EXE、`0010_SC`、`0000` 和 `Profile`。示例是 `D:\Entertainment\314曲海V2.7`。

「选择游戏根目录」要选这一层。如果选到 `0010_SC` 或 `Saves`，自动查找就会失败。武将页的「选择武将剧本」要选具体的 `scedaex` 文件。

## 2.2 工具目录是什么

工具目录里有 `看海工具.exe`、`fonts`、`gate-assets`、`version-dll-assets`、`使用说明`、`覆盖更新.ps1`。推荐放在游戏根目录下的独立文件夹。

## 2.3 数据文件都在哪

| 内容 | 默认位置 | 哪个页面用 |
|---|---|---|
| 固定个性、战法、政策、阵型、府域基础值 | `0010_SC\fixdataex.s14` | 个性编辑（固定）、战法制作、阵型编辑器、府域产出 |
| 剧本武将 | `0010_SC\scedaex01.s14`（可另选） | 武将编辑（剧本武将） |
| 自建个性 | `Profile\QQqun916308168\Saves\editpersonalitySC.s14` | 个性编辑（自建） |
| 自建武将 | `Profile\QQqun916308168\Saves\editdataexSC.s14` | 武将编辑（自建） |
| 地图 | `0000\Map.bin`、`0000\MapEx.bin` 及共享剧本 | 地图修改 |
| 进行中的存档 | `svdexSC` 开头的文件 | 不归这些页面管 |

**注意**：两个新页面改的是剧本和人物资料，不是进行中的存档。正在进行的战局已有自己的人物数据，通常不会跟着静态文件变。

## 2.4 两类保存的区别

| 对比 | 保存到文件 | 保存并应用 |
|---|---|---|
| 位置 | 个性、武将、战法、阵型、府域、地图页 | 游戏主程序页 |
| 写什么 | 你改的数据 | 功能开关和配套 DLL |
| 生效时机 | 游戏下次读取该文件时 | 完整重启游戏后 |
| 是否需要重启游戏 | 改完都要重启游戏 | 必须重启游戏 |

## 2.5 游戏开着能不能改

| 场景 | 能不能改 |
|---|---|
| 改共享剧本里的固定个性、战法、阵型、府域 | 建议先退出游戏，改完重启游戏 |
| 改剧本武将 | 先退出游戏，且要**新开**该剧本才生效 |
| 改自建个性、自建武将、固定内心 | **必须退出游戏**，否则游戏保存时会把旧数据写回 |
| 改地图 | 必须退出游戏 |
| 弹幕查询、战绩监控 | 需要游戏正在运行 |

**危险**：第一次大改之前，把你准备修改的 `fixdataex.s14`、`scedaex01.s14`、`editdataexSC.s14` 复制一份到别的地方。这是最省事的后悔药。

# 第 3 章 安装、升级和回滚

## 3.1 全新安装

见第 1 章 1.2 的 7 步。装好后工具目录里应该有以下内容：

| 文件／文件夹 | 作用 |
|---|---|
| `看海工具.exe` | 主程序，单文件自带运行库 |
| `fonts\` | 战法标题图用的三套字体 |
| `gate-assets\` | 关隘地区化等功能要用的地图和剧本资源 |
| `version-dll-assets\` | `version.dll`、`speed-battle.dll` 内存补丁组件 |
| `覆盖更新.ps1` | 覆盖安装脚本 |
| `使用说明\` | 本说明书和增量更新说明 |
| `licenses\` | 第三方许可证 |
| `先读我.txt` | 第一次使用提示 |

## 3.2 从旧版升级

1. 保存正在编辑的内容，完整退出游戏和看海工具。
2. 保留旧工具目录里的个人配置、战绩数据库和日志（升级器会自动保留，手动覆盖时不要删它们）。
3. 完整解压新版。
4. 把新版程序及资源覆盖到原工具目录。
5. 重新打开工具，检查游戏路径和原有配置是否正确。
6. 需要功能开关的，重新点一次「保存并应用」，再启动游戏。

**注意**：1.2.1–1.2.3 的用户请手动下载完整包覆盖安装一次，这几版的自动更新验证方式和现在不同，可能收不到 1.2.5。1.1.13 用户请先安装网站上的 1.2.0 国内转接版，再升级到 1.2.5。

## 3.3 用覆盖更新脚本安装（推荐给小白）

1. 完整解压压缩包到空文件夹。
2. 在解压出的 `栗子看海工具` 文件夹里按住 Shift 点右键 →「在此处打开 PowerShell 窗口」。
3. 先演练（不加 `-Install`，不写任何文件）：
   `powershell -ExecutionPolicy Bypass -File .\覆盖更新.ps1 -PackageDirectory . -InstallDirectory "D:\Entertainment\314曲海V2.7\栗子看海工具"`
4. 看输出的计划没问题，再加 `-Install` 正式安装。
5. 打开工具核对版本和路径。

## 3.4 程序内更新

工具左上角有「检查更新」。点一下会显示有没有新版本；有就出现「一键更新」，点了直接开始下载，不再弹整篇说明。下载、校验、备份、替换是自动的。

**注意**：游戏正在运行时工具会阻止更新并提示先退出游戏。更新失败会自动回退，不要急着手动删文件。

## 3.5 升级会保留什么

| 内容 | 结果 |
|---|---|
| `kanhai-*.json`、`battle-phase.ini`、`update-settings.json` 等配置 | 保留 |
| 弹幕设置、战绩数据库、日志 | 保留 |
| `游戏目录备份\` | 保留，更新器不触碰 |
| 旧 Python 组件 | 移入 `.update-backups` 后删除 |

## 3.6 回滚（降级）

本版不支持程序内降级。要回退时：退出游戏和工具 → 下载你想要的旧完整包 → 用其中的 `覆盖更新.ps1` 重新安装。工具配置、战绩数据库和日志会保留；被删掉的旧组件在安装目录的 `.update-backups` 里。

## 3.7 启动没窗口怎么办

1. 确认是完整解压后在本地文件夹运行，不是在压缩包、网盘同步目录或临时目录里。
2. 确认工具目录里有 `fonts`、`gate-assets`、`version-dll-assets`。
3. 查看工具目录下有没有 `startup-trace.log`、`logs\` 里的最新日志。
4. 若安全软件报错，保留提示里的文件路径和原因。
5. **不要**用反复覆盖人物资料的方式来处理启动问题。

**提示**：任何时候拿不准，先点「重新载入」或「还原改动」，再重新做一遍。这比在一个改乱的状态上继续改安全。

# 第 5 章 游戏主程序页：14 个功能开关

## 5.1 先选游戏

1. 进「游戏主程序」页。
2. 点「选择 EXE」，选你实际在用的游戏主程序。
3. 页面会显示游戏目录；点「刷新状态」可以看当前开关和备份状态。
4. 「重建备份」用于重新记录原始 EXE 备份（一般不用动）。

## 5.2 十四个开关一览

| 开关 | 作用 | 使用提示 |
|---|---|---|
| 邻接 | 交趾⇄昆明相邻 | 地图关系变化，改完重启游戏 |
| 战绩监控 | 采集部队伤害与城市兵力 | 采集功能的开关 |
| 梓潼屯兵修复 | 梓潼到汉中的定向修复 | 针对特定路线问题 |
| 随机内心 | 按武将编号固定内心，可手动重新生成 | 与固定内心配合使用 |
| 施政优化 | 施政排序与格数上限 | 点「格子…」「权重…」细调 |
| 关隘地区化 | 十关改为普通地区 | 地图结构变化，改完重启 |

## 5.3 怎么开关才生效

1. 退出游戏。
2. 在「游戏主程序」页拨动开关。
3. 点「保存并应用」。
4. 完整启动游戏。
5. 要关闭时同样：先退出游戏 → 关掉开关 →「保存并应用」→ 重启游戏。

**注意**：只拨开关不点「保存并应用」不会写任何文件。页面上的提示会告诉你有没有保存成功。

- EXE 备份：`<主程序>.siege-backup`。
- 邻接备份：`邻接切换备份\fixdataex.s14`。

- 游戏目录日志：`kanhai-version-dll.log`、`battle-phase.log`；工具日志在 `logs\`。

## 5.6 逐个开关说明

### 邻接

把交趾和昆明判定为相邻。开启后工具会改写 `fixdataex.s14` 里的地图邻接关系，原文件备份到「邻接切换备份」。相邻关系影响行军路径和补给判定，改完重启游戏，读档后按新邻接计算。

### 战绩监控

采集部队伤害与城市兵力数据，供「战绩监控」页查询。需要游戏运行中才会采集；关闭后不再记录新数据，已有数据库不受影响。

### 梓潼屯兵修复

修复梓潼到汉中的定向屯兵／运兵路线判定。只影响这一条路线，其他路线按原逻辑。改完重启游戏生效。

### 随机内心

按武将编号固定生成内心，避免每次新开剧本时内心随机。和武将编辑页的「保存固定内心」配合：有固定值的武将优先用固定值，没有的按编号生成。开启后游戏内会出现「重新生成内心」按钮。必须「保存并应用」后完整重启游戏。

### 施政优化

调整施政排序与格数上限。卡片上的「格子…」可以分别设置六种主义、五类施政的初始格数与最终上限，并能保存成个人默认模板；「权重…」可以调整 31 项施政效果权重。对 AI 势力的施政同样生效。改完重启游戏，新开或推进时按新规则计算。

### 关隘地区化

把十处关隘改成普通地区。会改变地图结构和据点归属，原文件备份到「关隘地区化备份」。改完必须重启游戏；旧存档的地图数据可能保留原关隘状态，需要新开局或按存档情况核对。

### 伪报曲线

自定义伪报成功率曲线，可以调六个智力差节点。「曲线…」打开编辑器调整节点后保存。对敌我双方的伪报判定都生效。

### 海外交易

把海外交易安排在出征、运输之前，并跳过警戒与君主前线限制。关闭时会还原交易顺序、警戒及君主前线条件，原文件有独立原树备份。只影响 AI 的交易顺序判断。

### 幕府协同

政策效果：5 级政 90 减 1，10 级政 85 减 2；本政策自身不减。配套数据和 DLL 由工具一起部署。适合想让幕府类政策更划算的玩法。

### 战法提示保护

悬停箭雨、鼓舞、铁壁等战法时游戏会闪退的话，开启它。**正常游戏请保持关闭**，因为它会改变战法提示的显示方式。

### 自建武将优先继位

AI 继位时优先选合格的自建武将；没有符合条件的，仍按原规则继位。只影响 AI，不影响玩家手动立储。

### 四档速度

鼠标移到「进行／停止」按钮上会展开四箭头速度档：悬停四箭头变黄并显示提示，点选后显示橙色进入第四档；点任一原档位退出四档。第四档减少时段之间的等待，实际提速随局势和帧率变化。窗口化和无边框模式优先支持。

### 伤害修复

针对「旧战斗效果占用队列时，原版可能跳过当天普通攻击检查」的情况：保留当天的检查，等旧批次结束后执行一次。队列繁忙时日期可能短暂停留。它不改变伤害公式，也不涵盖所有没飘字的情况。可以只开四档或只开伤害修复。

### AI 关隘驻将

AI 按战法给关隘安排守将：

- 前线关隘：目标驻守 1–3 人，优先统率不超过 90、对应战法属性（武力或智力）低于 100 的武将；合格人选不足时从同势力主城补员。
- 太守：从合格驻将里按关隘战法对应属性挑选；新到关隘的武将也会复核，统率超过 90 的优先调回。
- 后方关隘：目标只留 1 人；已有太守在位时尽量保留。
- 调令需要时间：命令要等游戏接受并执行，人员到达要行军／调动时间。开启后建议先推进一旬观察。
- 只影响 AI：不会限制玩家手动调动。个别关隘缺少战法配置、或势力没有可调武将时，会跳过该关隘。

# 第 6 章 个性编辑

## 6.1 页面长什么样

- 顶部两个来源：「固定个性」和「自建个性」。
- 顶部有「选择游戏根目录」「手动配置」「保存到文件」「重新载入」「还原改动」。
- 自建来源多一个「新建个性」。
- 中间是表格，可以横向滚动；上面是搜索框。

## 6.2 修改一个已有个性（8 步）

1. 左侧点「个性编辑」。
2. 顶部选择「固定个性」或「自建个性」。
3. 在搜索框输入名称或编号；清空搜索框可以看全部记录。
4. 横向滚动表格，找到要改的列。
5. 点条件、效果或类型单元格，打开下拉菜单；每个选项都带游戏编号和名称。
6. 在数值格输入整数，点其他格提交这一格的修改。
7. 点「保存到文件」。
8. 点「重新载入」核对数值，再在游戏中重新加载对应内容。

**提示**：下拉菜单右侧有滚动条，可以拖着快速跳。按 Esc 取消当前格的编辑。「还原改动」放弃本页尚未保存的修改。编号是记录身份，不要在表格里随意改写。

## 6.3 新建一个自建个性（8 步）

1. 顶部选「自建个性」。
2. 点「新建个性」，表格出现一条新记录。
3. 填名称。名称最多 5 个字符，超出会提示。
4. 选触发条件 1、触发条件 2，以及最多两组效果。
5. 填对应效果数值；第二组不用时选「000 无」，数值填 0。
6. 按所选条件的要求填「条件 1 扩展」。
7. 保存后重新载入，确认新个性还在列表里。
8. 到「武将编辑」把新个性分配给目标武将，再保存武将资料。

**注意**：保存个性定义和分配给武将是两个步骤，只做第一步游戏里没人会带着它。

## 6.5 固定个性和自建个性的区别

| 对比 | 固定个性 | 自建个性 |
|---|---|---|
| 来源文件 | `0010_SC\fixdataex.s14` | `Saves\editpersonalitySC.s14` |
| 数量 | 编号 0–255 | 100 个自建槽，通常从 256 开始 |
| 记录长度 | 固定表记录 | 63 字节存档记录 |

## 6.6 类型、条件和标志怎么理解

- **类型**：00 无效用于空白或无效记录；01 正面是普通正面个性；02 负面是负面个性；03 金色／固有是强力或固有个性。旧界面的「原值 3」就是 03。
- **条件和效果**：条件决定什么时候、对谁生效；效果决定触发后做什么。效果数值的单位随效果变化，可能是固定量、百分比档位或启用标记。
- **条件参数**：不是百分比，更像目标范围选择值。三格友军是否包括自己、是否受到攻击触发，都靠它区分。
- **扩展参数**：「兵力低于指定值」用扩展参数 A 存阈值（如 5000）；阵型条件用扩展参数存阵型内部参数。
- **适用标志**：不是可以随便组合的标签。新手请整组照抄同类个性，不要自己对十六进制位加减。

## 6.7 两个可以直接照做的例子

### 例子一：把疾走的机动加成改大

1. 固定个性里搜「疾走」。
2. 先记下原来的条件、效果、数值和适用标志。
3. 保留「船舰与兵器除外」的条件组合。
4. 保留效果「004 机动增减」，把原始数值 4 改成 6（约等于 +30%）。
5. 保留原有适用标志 12，保存文件。
6. 新开或重新加载读取该共享数据的游戏内容，核对效果。

这个例子沿用已有模板。实际战斗中还可能有政策、地形和其他加成，工具里的原始数值不代表最终面板。

### 例子二：做一个个「背水试作」自建个性

1. 新建自建个性，命名「背水试作」。
2. 条件 1 选「020 兵力低于指定值」。
3. 条件 2 选「001 自部队」。
4. 效果 1 选「019 全能力增减」，数值填 2。
5. 效果 2 选「000 无」，数值填 0。
6. 条件 1 扩展填 5000，保存。
7. 把该个性分配给测试武将，再保存武将资料。

意思是「兵力低于 5000 时全能力增加两档（约 +10%）」。请在游戏里用相同兵力条件核对实际效果，再拿去正式用。

## 6.8 自建个性为什么少几列

自建个性用的是另一种 63 字节存档记录。游戏载入时会根据条件和效果自己生成类型和适用标志，所以界面不提供独立的标志编辑。固定个性的独立条件参数、类型、适用标志、手写说明，在自建存档里没有相同的栏位。

自建存档本身存了条件 2 扩展，但当前曲海 V2.7 的账号载入路径没有应用它，所以工具用「条件 2 扩展（只读）」显示原值。

### 直接百分比效果

异常状态持续时间、士气衰减、兵粮消耗、占领范围所需兵力、建设速度、捕获概率、回合伤兵恢复等，通常直接使用百分数或近似百分数。作用于敌军的效果可能用负值表示反向增减，第一次做时照抄同类个性的数值方向。

### 布尔（开关）效果

异常状态无效、混乱／止步／挑衅无效、无视 ZOC、不会负伤／战死、不会被俘、包围无效、解除陷阱等，一般 `1` 表示启用，`0` 表示关闭。

### 士气与固定资源

士气增减直接填点数（如 10、20）；固定资金、固定兵粮直接填数量（如 500、1000）。

### 特殊离散或复合效果

- 「040 所受伤害减少」：现有「缮甲」中数值 1 约等于减少 25%。
- 曲海新增复合效果可能把概率、士气等多个数值编码在同一个整数里，例如「怖慑」的数值 360 实际语义是「60% 概率使士气 -3」，不能按 360% 理解。

**危险**：遇到这类效果必须复制现有个性的原始值，不要自己套百分比公式。

## 7.8 最容易填错的六件事

1. 把效果原始值当成直接百分比（能力类要 ×5%）。
2. 把十六进制适用标志当十进制填。
3. 把阵型内部参数当成阵型显示 ID。
4. 忽略条件参数里 -1、0、11 的区别。
5. 在 V2.7 里把固定 ID 256–258 当成普通新增槽位（256 以后会被当作自建个性）。

# 第 8 章 武将编辑

## 8.1 页面长什么样

| 对比 | 剧本武将 | 自建武将 |

## 8.3 找到要改的武将

1. 进「武将编辑」，选来源。
2. 在搜索框输入姓名或编号。
3. 点左侧列表里的武将，右侧显示他的资料。
4. 要改别的剧本，先点「选择武将剧本」，选对应的 `scedaex` 文件。

**提示**：切换武将或目录之前，如果当前武将还有没保存的改动，工具会提示「先保存或还原」。先点「保存到文件」或「还原表单」再走，避免改到别人身上。

1. 「基本」页找到「能力」。
2. 拖动滑条，或在数值框直接输入统率、武力、智力、政治、魅力。
3. 每项允许 0–255，雷达图会实时跟着变。
4. 点「保存到文件」，再「重新载入」核对。

**注意**：工具按字节写入 0–255，但游戏的某些自建武将导入流程会自己限制范围（常见是 1–100）。写完还要在实际加入剧本的流程里核对。

- 「基本」页提供 9 个个性槽和 10 个战法槽，选项显示编号加名称，不需要的槽选「无」。

- 生年、卒年按年份填；剧本来源还有登场年。
- 相性允许 0–149，参与多项人物关系判断。相性大不代表能力高。
- 父亲、母亲、配偶用下拉选择，显示编号加姓名；选「000 无」表示没有对应关系。

## 8.9 批量添加亲爱和厌恶（8 步）

1. 点「选择亲爱武将…」或「选择厌恶武将…」。

3. 勾选目标武将。
4. 换一个搜索词（姓名或编号，例如 0393）继续勾选；切换搜索词会保留已选对象。
5. 每组最多 8 人。取消已选对象后可以再添加别人。
6. 点弹窗「确定」，回到人物页检查摘要。
7. 点武将页「保存到文件」，这时才真正写入。
8. 「重新载入」核对名单。

**注意**：弹窗「取消」会放弃本次勾选。亲爱和厌恶分别保存。改了一个人的名单，不保证游戏自动把对方的名单改成相同关系。

| 字段 | 说明 |

## 8.11 新建一个自建武将（7 步）

1. 切换「自建武将」，点「新建武将」。
2. 填姓名、性别、人物类型和头像资源编号。
3. 配好五维、个性、战法、阵型和政策。
4. 到「个人」页设置生卒年、相性和关系。
5. 按需要保存固定内心，到「列传与高级」填列传。
6. 点「保存到文件」，再「重新载入」搜索该武将确认存在。
7. 在游戏里把自建武将加入目标剧本。

**提示**：头像按资源编号或本地同名图片预览。同名图片会标注「参考图」，显示预览不代表已经替换了游戏里的立绘文件。游戏资源包的自动提取和写回尚未接入。

| 按钮 | 作用 |

| 重新载入 | 从文件重读，放弃未保存改动 |
| 还原表单 | 只把当前表单恢复成最近一次读取的样子 |

# 第 9 章 固定内心和随机内心

## 9.1 界面的 1 到 5 是什么

九项普通内心使用五档：1、2、3、4、5 分别对应内部值 -20、-10、0、10、20。自建武将另有资金、军粮、士兵三选一的物资偏好。

## 9.2 保存固定内心（6 步）

1. 退出游戏，选择「自建武将」。
2. 打开目标武将的「个人」页。
3. 勾选「保存固定内心」，选各项 1–5 档及物资偏好。
4. 点「保存到文件」。
5. 到「游戏主程序」页打开「随机内心」，点「保存并应用」。
6. 完整重启游戏，新开剧本时使用保存的固定值。

已有固定内心的武将优先使用固定值；没有固定值时，组件按武将编号生成稳定的默认值。

## 9.3 游戏里的「重新生成内心」

游戏内按钮会按规则重新生成一套值，确定后保存覆盖，返回则放弃本次生成。生成后想改，仍要回到工具里改「保存固定内心」的值。

## 9.4 清除全部固定内心（6 步）

1. 先退出游戏。
2. 打开「武将编辑」，顶部选「自建武将」。
3. 确认路径栏对应需要清理的账号。
4. 先保存或还原当前表单的修改。
5. 点顶部「清除全部固定内心」。
6. 阅读确认提示，确定后清除当前文件末尾的内心扩展区。

清除后人物资料的原始部分保留，已有战局继续用该局内心。若随机内心开关还开着，下次新开剧本会按编号生成默认值，游戏以后保存人物资料时可能又写出内心记录。

**注意**：按钮置灰表示当前人物档没有内心扩展。这个按钮清理当前账号的**全部**记录，不能只删一个人的内心。

## 9.5 当前兼容边界

内心资料使用人物文件末尾的 KHHEART 扩展。游戏组件要求扩展里的条目和有效人物记录配齐。若新增人物后只保存了部分内心，存在载入时拒绝整份扩展并回退默认值的边界情况。

另外，出现过 Windows 拒绝读取核心 DLL、游戏内按钮缺失的情况。具体拦截来源仍在排查，本版不把它列为已修复。

## 9.6 排查用日志

游戏目录下的 `kanhai-version-dll.log`、`battle-phase.log` 会记录 DLL 加载和补丁状态。若提示拒绝访问，保留文件路径、报错文字和本次启动时间，便于定位。

# 第 10 章 用 V 大修改自建武将

## 10.1 为什么需要兼容副本

V 大旧版对自建武将文件长度有严格要求。固定内心扩展会让文件超过原版 172950 字节，所以即使武将本体正确，V 大也可能提示文件打不开。

## 10.2 一次完整操作（8 步）

1. 退出游戏。
2. 工具里打开「武将编辑 → 自建武将」。
3. 点「手动配置 → 导出 V 大兼容武将副本」。
4. 选一个独立文件夹，文件名保持 `editdataexSC.s14`。
5. 用 V 大打开这个副本，修改并保存。
6. 回看海工具，点「手动配置 → 导入 V 大编辑后的武将副本」。
7. 选择刚保存的副本，核对提示里的原档路径后确认。
8. 工具合并武将数据、保留对应内心并重算校验；重新载入检查结果。

**注意**：导出的副本只有武将本体。导入时按同槽位和相同编号保留原固定内心。如果你在 V 大里把同槽位同编号换成了另一个人物，会继承那个位置原有的内心。

## 10.3 已经清除内心的情况

如果已经用过「清除全部固定内心」，原文件恢复为原版长度，可以直接交给 V 大读取，不需要副本流程。之后若游戏又写出内心扩展，就需要重新用副本流程。

# 第 11 章 战法制作

## 11.1 页面能做什么

- 读取共享剧本里全部 0–200 号战法记录。

| 项 | 说明 |
|---|---|
| 名称 | 最多 4 个 UTF-16 代码单元 |

1. 在右侧切换配色（九套明亮配色）。

4. 只改效果不写图时，不要勾选写图；只更新图片时用「只写标题贴图」。

**注意**：标题图和完整粒子演出是两套资源。本版不提供全新镜头或粒子演出编辑器，也不提供任意新效果代码。

## 11.5 保存与清空

- 保存会直接覆盖目标文件，不生成持久备份。
- 定义与贴图统一提交；任一文件失败时，用内存中的原内容整组回退，避免只写了一半。
- 只在本次操作期间暂存原内容，不提供历史版本恢复。
- 清空使用固定空记录，会修复全部槽位用满后仍残留效果的问题。原有标题资源保留，190–200 由工具创建的独立标题资源可随清空移除。

## 13.3 批量修改

1. 先用搜索或筛选圈定要改的府。
2. 选择「批量设定固定值」或「按百分比缩放」。
3. 留空的项目保留各自原值。
4. 确认后应用，可撤销、恢复。
5. 保存前核对改动摘要。

## 13.4 双城对比

1. 打开「双城对比」。
2. 选择城市 A、城市 B，左右查看各自所有府的三项基础值。
3. 底部列出府数量、三项总基础值、A 减 B 差额及相对 B 的百分比。
4. 支持互换城市；页面未保存的修改也会实时反映。

统计按共享剧本默认都市圈，包含城市中心；两侧府列表各自独立。

## 13.5 保存规则

- 直接保存当前 `fixdataex.s14`，**不生成备份、副本或同目录临时文件**（这样目录不允许新建文件时也能保存）。
- 保存前验证格式与目标字段；保存时只写修改项及完整性校验字段，写后完整回读。
- 其他页面对不同字段的有效修改会保留；同一项数值冲突时会提示处理。
- 写入中断时尝试用内存中的原值回退。
- 保存完成后保留地图位置、筛选和选中府。

## 13.6 边界

三项数值是基础参数，不是实际月收入；人口、开发、武将等仍参与结算。保存前退出游戏，保存后重启游戏核对。目前支持已展开的曲海 2.7／2.8 布局，游戏内最终结算未逐项实机验收。

# 第 14 章 地图修改（三维地图编辑）

## 14.1 打开和看视角

1. 左侧点「地图修改」。
2. 打开游戏目录后点「三维地图编辑」。
3. 查看模式下：左键拖动或右键拖动平移，Shift 加左键拖动旋转，滚轮缩放。
4. 「全图」回到整体视野，「近景」进入局部视野。
5. 点一个格子，右侧显示坐标、地形和所属府域。

恢复原始地图时使用软件旁「原始地图」里首次打开时保存的副本。首次打开时目录里已有的修改也会进入这份副本。

地形显示只是工具的预览样式：普通地形起伏为首版预览的 25%，险山和崖补齐了显示高度，减少遮挡。它不修改游戏地图或原生高度资源。

## 14.2 改地形和贴图

1. 点「地形＋贴图」，在右侧选目标地形。
2. 设置格子半径。0 格改单格，大半径刷一片。
3. 在地图上涂抹，观察地表预览。
4. 要统一处理多个分散格子时，勾选「多选格子后统一修改」，选好范围后点「应用」；重复点已选格会取消选择。
5. 「仅贴图」只改外观材质；改逻辑地形时要核对水陆和通行情况。

## 14.3 改高度

抬高、降低和平滑使用高度笔刷。按住左键会持续修改，也可按住拖动。右侧调整半径和强度，点「撤销上次高度笔触」撤回整个笔触。

「视图与水面」里的水面标高只是预览设置，不能单靠它改变游戏的水格规则。

## 14.4 改府域归属

1. 点「府域」，在右侧选目标府。
2. 选笔刷半径，或勾选「拖动框选府域格子」。
3. 选格子，核对预览范围后应用。
4. 要改整个府的都市归属时，用「当前府域所属都市」选接收都市，点「暂存都市圈」。
5. 发现选错时，用恢复原归属或撤销对应改动，再检查。
6. 切换「范围显示」可以查看府域和都市圈。

## 14.5 移动、新增和删除据点

| 操作 | 步骤 |
|---|---|
| 定位 | 点「据点」，选「当前据点」，点「定位」 |
| 移动 | 先在地图选目标格，再点「移动到选格」 |
| 新增 | 填名称，选府、都市或关隘以及所属都市，在地图选放置位置，点「在选格新增」 |
| 删除 | 选接收府域；删除都市还要选并入的都市圈；确认预览 |
| 撤销 | 点「撤销上次据点操作」 |

- 新增据点要在普通陆格上操作；都市和关隘使用原版固定槽位。
- 当前程序支持 51 座都市、10 处关隘、500 个府域记录。满额时先删再增。
- 都市和关隘的名称最多 3 个 UTF-16 字符，府最多 17 个。
- 删除会同步转交原府域的格子，并重新计算受影响的府域邻接。

## 14.6 城市对

先选一座都市，再选连接目标，可以「建立城市对」或「移除城市对」。新增关隘会自动建立与所属都市的连接。连接关系影响地图结构，改完要在游戏里核对实际路径。

## 14.7 批量处理据点

1. 展开「批量处理据点」，按名称、编号或都市圈筛选。
2. 按 Ctrl 多选，或用 Shift 选连续范围；也可点「选中当前都市圈」。
3. 删除时指定「批量删除的接收府域」，检查是否同时删除都市圈全部府。
4. 点「预览批量删除」，阅读将删除的据点和府域分配结果，再确认。
5. 只改都市归属时，选目标都市圈，点「改挂到所选都市圈」。
6. 重画选中区域时，点「按道路与地形重划所选府域」并检查预览。
7. 要增加当前都市圈的府数时，填目标府数，点「补足府数并预览划界」，核对后确认。

「将可通行地块分给相邻府域」会影响删除后的接收方案。若预览提示无接收府或邻接限制，调整选区或接收府再预览。超过游戏邻接槽位时，弹窗会列出超限府和相邻地区，也可点「查找其他接收府域」试算附近备选方案。

## 14.8 工程保存和导出

| 按钮 | 作用 |
|---|---|
| 保存编辑工程 | 按名称保存当前编辑进度 |
| 按名称读取工程 | 用同一游戏目录和同一地图版本继续编辑 |
| 导出地图设计 | 保存设计资料 |
| 导出独立测试包 | 生成两张规则地图、共享数据、视觉资源和目标剧本，用于隔离验证 |
| 保存原始地图副本 | 另存首次打开时的数据 |

工程保存当前结果，读取后撤销历史从读取时重新开始。

## 14.9 真正写进游戏

1. 填写「据点改动的目标剧本编号」，默认是 1，确认是要玩的剧本。
2. 点「保存到游戏目录」。
3. 弹窗会显示目标路径和剧本编号，确认后直接覆盖发生变化的游戏文件。
4. 等待页面报告成功，再完整重启游戏核对。

**危险**：这次覆盖不另建备份，而且共享地图文件可能影响同目录的其他剧本。请先退出游戏、先自己备份游戏目录。都市被删除时，驻该据点的武将位置引用会转到接收都市，武将自身所属势力保留。原版固定剧情里的据点编号引用仍由剧情使用，改过地图后应在目标剧本里检查相关事件。

## 14.10 覆盖中断怎么办

如果上一次保存已经生成了包含「修改记录.json」的目录，但覆盖中途失败：

1. 展开「继续写入已生成的地图」。
2. 填写那份目录。
3. 点「核对并继续覆盖」。
4. 工具会先校验生成文件、目标游戏目录和原文件版本，再继续写入。

生成完成后若覆盖失败，右下角日志会显示已保留结果的路径。

## 14.11 实机核对清单

改完地图后，进游戏至少确认：新开局能进、移动寻路正常、事件能触发、存读档正常、据点归属和所在势力正确。测试已覆盖画笔、长按升降及撤销、据点增删移动、城市圈与城市对、导出后的字节回读与剧本解压验证，但具体游戏表现仍需实机核对。

# 第 15 章 弹幕查询

## 15.1 准备

1. 进「弹幕查询」。
2. 在「直播间」输入直播间号或 `live.bilibili.com` 链接。
3. 「游戏进程」区域点「刷新进程」，选正在运行的 SAN14PK 进程。
4. 需要执行游戏查询类指令时，游戏必须已经连接。

- 表格显示接收时间、观众、弹幕内容。
- 可以筛选、清空、导出 CSV。
- 右下角「运行日志」显示连接、心跳、查询结果；可「重新自检」「清空日志」「日志目录」。

- 超过 70 秒未收到心跳会提示等待服务器响应并自动重试。
- 请勿在公开场合暴露账号密码或访问令牌。

## 16.1 页面结构

3. 确认数据库和存档目录正确（可「浏览…」改）。

5. 点「开始记录」，进入游戏正常游玩。

## 16.4 探针和版本验收

- 没有该文件时默认不附加游戏，界面会提示「待版本验收」。
- 这不影响普通只读采集。
- 抓取探针可在采集设置里勾选「启用抓捕探针（capture_hook）」。
- 现有数据库里若只确认了被俘武将、没有抓捕者证据，界面会明确说明不能推测。

## 16.5 官职字段的注意点

1.2.2 修复了「采集到的武将官职 ID 恒为 0、名册显示无效」的问题。**历史记录不会自动改写**，需要在 1.2.5 下重新采集一局，官职才会更新。

# 第 17 章 出问题按这个顺序检查

## 17.1 常见问题对照表

| 现象 | 先查什么 | 再做什么 |
|---|---|---|
| 改了游戏里没变化 | 路径栏是否指向正确文件 | 确认点了「保存到文件」；确认进的是对应剧本新开局 |
| 表格里数字标红 | 当前格数值超出允许范围 | 改成允许值，或按 Esc 取消该格 |
| 提示先保存或还原 | 当前武将有未保存改动 | 先「保存到文件」或「还原表单」，再切换 |
| 提示文件已被其他程序修改 | 游戏或另一个修改器占用文件 | 关掉它们，点「重新载入」再改 |
| V 大打不开人物档 | 文件是否还带内心扩展 | 用第 10 章的兼容副本流程 |
| 游戏里重新生成内心按钮没出现 | 随机内心开关是否保存并应用 | 退出游戏 → 核对开关 → 保存并应用 → 重启 |
| 核心 DLL 被拒绝读取 | 安全软件或权限 | 保留 `kanhai-version-dll.log`、`battle-phase.log` 和报错原文 |
| 启动没窗口 | 是否完整解压、是否在本地目录运行 | 看 `startup-trace.log` 和 `logs\` |
| 地图保存后进不去游戏 | 是否备份过原文件 | 用备份恢复，再用「继续写入已生成的地图」流程 |
| 一键更新失败 | 游戏是否还在运行 | 退出游戏重试；失败会自动回退 |
| 弹幕收不到 | 直播间号和网络 | 看运行日志和心跳提示，重新连接 |
| 战绩读取为空 | 数据库和存档目录 | 核对路径，重新「↻ 读取战绩」 |

## 17.2 反馈问题请带上这些

- 工具版本号（左上角或主界面）。
- 游戏主程序完整路径。
- 你做的每一步（从打开哪个页面开始）。
- 报错原文或截图。
- 改的是固定个性、自建个性、剧本武将还是自建武将。
- 涉及内心按钮时，提供本次启动时间及对应日志。
- **不要**提供账号密码或访问令牌。

## 17.3 怎么恢复自己改坏的数据

1. 有原始文件副本时：退出游戏，把副本覆盖回去。
2. 恢复整个 `editdataexSC.s14` 会同时恢复其中武将资料和内心扩展。
3. 只想清内心：用工具的「清除全部固定内心」。
4. 地图或剧本：用你自己备份的文件覆盖，或用游戏目录的「原始地图」副本。
5. 工具配置问题：删掉坏掉的 `kanhai-*.json` 前先备份。

## 附录 F 安全边界提醒

1. 修改前先备份你准备改的文件，尤其是 `fixdataex.s14`、`scedaex01.s14`、`editdataexSC.s14` 和游戏地图。
2. 改数据前退出游戏；改完完整重启游戏再核对。
3. 战法、阵型、地图、府域保存都不自动生成备份，需要你自己留副本。
4. 不要用工具生成的测试 EXE 覆盖正式游戏 EXE。
5. 不要把游戏目录的 DLL 副本放进工具包的资产目录。
6. 本说明书只描述已验证的文件级行为；游戏内最终结算、直播捕获和不同修改版的内存布局仍需按实机核对。
